# Mini-Courier Planner

DAA Capstone Assignment (ETCCDA302), K.R. Mangalam University

This is a small courier planning program in Python. It takes a list of parcels and a road map, and gives:
- which parcels to deliver first (sorted by deadline)
- which parcels to load in the van (best value within the weight limit)
- the shortest roads to each customer
- the order in which to visit the customers

## Algorithms used
- Merge sort - sort parcels by deadline
- 0/1 Knapsack (Dynamic Programming) - choose parcels for one trip
- Dijkstra's algorithm - shortest paths
- Nearest-neighbor TSP - delivery route order

## How to run
You need Python 3. For the benchmark chart, also run `pip install matplotlib`.

1. Make the sample data:
   `python generate_data.py`
2. Run the planner on small data:
   `python main.py --data data/small --capacity 40`
3. Run on large data:
   `python main.py --data data/large --capacity 2500`
4. Run the tests:
   `python -m unittest test_planner -v`
5. Run the runtime comparison (makes a chart in the results folder):
   `python benchmark.py`

## Files
- `main.py` - runs the whole planner
- `sorting.py` - merge sort, quick sort, heap sort
- `knapsack.py` - 0/1 knapsack
- `graph.py` - graph, Dijkstra, nearest-neighbor TSP
- `data_io.py` and `generate_data.py` - make and read the data files
- `benchmark.py` - measures runtime
- `test_planner.py` - tests
- `data/` - sample data (small, medium, large)
- `screenshots/` - output screenshots
- `results/` - runtime table and chart

## Data files
- `parcels.csv`: id, weight, value, deadline, dest
- `graph.csv`: u, v, distance (node 0 is the depot)

##
**Note:** The data in the data/ folder is not real. It is synthetic demo data generated by generate_data.py with random values, used only for testing and runtime comparison.
